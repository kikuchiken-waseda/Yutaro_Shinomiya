# 新聞見出しのポジネガ分析システム
報道の「量」と「トーン」の年次推移を可視化するためのツール群。
- 福島県産農産物に関する新聞見出しを収集
- 形態素解析とポジネガ判定

## 目的
震災後、福島県産農産物の一部品目では価格が震災前の水準(A)に戻っていない。
その背景に、メディアが福島県産をどう語ってきたかという「ことば」の影響(B)が
あるのではないか、という仮説を検証する。
 
このシステムが担うのは、そのうち**言語データ側（B）の定量化**である。
 
```
A: 価格データ  ─┐
                 ├→ 突合して相関分析 → 考察・提言
B: 言語データ  ─┘   ← このシステムが担当する範囲
```

## 必要な環境
- Python 3.9 以上
- macOS / Windows / Linux

### インストール
```
bash
pip3 install mecab-python3 ipadic pandas
```
 
`ipadic` を使う理由は、日本語評価極性辞書がIPADICの語彙体系に準拠して
作られているため。unidic系だと原形の取り方が合わず、ヒット率が落ちる。
 
`externally-managed-environment` エラーが出る場合は仮想環境を使う。
 
```
bash
python3 -m venv venv
source venv/bin/activate
```
Windowsは 
```
venv\Scripts\activate
pip install mecab-python3 ipadic pandas
```

### 極性辞書の入手
東北大学 乾・岡崎研究室が公開している「日本語評価極性辞書」を使う。 
- 配布元: https://www.cl.ecei.tohoku.ac.jp/Open_Resources-Japanese_Sentiment_Polarity_Dictionary.html
-（参考文献として記す必要あり）
- 用言編: `wago.121808.pn`（動詞・形容詞）
- 名詞編: `pn.csv.m3.120408.trim`

保存時に `.txt` が付与された場合はリネームすること。（macだとつきがち）
 
```
bash
mv wago.121808.pn.txt wago.121808.pn
```
 
どちらか一方だけでも動作するが、両方あった方が判定率が上がる。

## 入力データの形式
tsv作りに使用している[スプレッドシート](https://docs.google.com/spreadsheets/d/1LmQ-NqNdvjkp2_eIT3MmW6QoMJ8o93bYGmnedDutN90/edit?usp=sharing)
 
`headlines.tsv` はタブ区切り。1行目がヘッダ。
 
| 列名 | 内容 | 例 |
|---|---|---|
| 品目 | 対象品目 | コメ |
| 紙名 | 新聞社 | 朝日 |
| 発行日 | YYYY-MM-DD | 2011-04-22 |
| 年 | 発行年 | 2011 |
| 見出し | 記事見出し | コメ作付け禁止　福島第一原発… |
| 備考 | 掲載面など | ５総合（全国面） |
 
備考欄に「全国面」という文字列が含まれていると、
全国面と地方面を分けた比較が自動で実行される。（別にやる必要はない気もする）
 
### 収集方法
- 朝日新聞クロスサーチ（早稲田大学図書館から利用可）で検索
- 見出しを手作業で転記する。（めっちゃだるい他の方法欲しい）
 
**検索クエリ設計の注意**
- 「米」は新聞表記で米国を指すため、稲作の意味では「コメ」で検索する
- それでも「コメント」「コメリ」「コメディー」「込めた」が混入する
  → スクリプト（data.py）側で `NOISE_MARKERS` として自動フラグを立てている
- 桃は人名・桃太郎・他県産との混同があるため「福島県産 桃」等で絞る

**規約上の注意**
- 記事本文の一括ダウンロードやテキストマイニング用途での大量取得はデータベースの利用規約で制限されている場合がある。
- 本システムは**見出しのみ**を対象とし、本文は扱わない。

## 出力
 
### headlines_scored.tsv

入力データに以下の列が追加される。
 
| 列名 | 内容 |
|---|---|
| スコア | −1.0〜+1.0。ヒットした極性語の平均 |
| 辞書ヒット数 | 中立語を含む、辞書に載っていた語の数 |
| 極性語数 | 中立を除いた、ポジまたはネガの語の数 |
| 判定 | ポジティブ / ネガティブ / 中立 / 判定不能 |
| ノイズ | 「コメント」等を含む見出しに「要確認」 |
| 寄与語 | 判定に使われた語とスコア。**目視確認用** |
| 分かち書き | 形態素解析の結果 |
 
### yearly_sentiment.tsv
 
年次サマリ。件数、判定可能数、平均スコア、ポジ比率、ネガ比率。
 
### 標準出力
 
- 判定の内訳
- 年次サマリ
- 全国面 vs 地方面の比較
- 年別の頻出語トップ8
- 最もポジティブ／ネガティブと判定された各5件（**寄与語付き**）

## 判定ロジック
1. MeCab（IPADIC）で見出しを形態素解析し、名詞・動詞・形容詞・副詞を抽出
2. 各語を辞書と照合する。優先順位は **補助辞書 > 用言編 > 名詞編**
3. ヒットした語のスコアを平均して見出しのスコアとする
4. 閾値（既定 ±0.10）でポジ／ネガ／中立に分類
5. 極性語が0語の見出しは「判定不能」とする

### 主な設定値
 
`data.py` の冒頭で変更できる。
 
| 変数 | 既定値 | 説明 |
|---|---|---|
| `THRESHOLD` | 0.10 | ポジ／ネガの判定閾値 |
| `MIN_HITS` | 1 | これ未満の極性語数で判定不能 |
| `TARGET_POS` | 名詞/動詞/形容詞/副詞 | 判定対象の品詞 |
| `NOISE_MARKERS` | コメント等 | ノイズ判定に使う文字列 |

## 補助辞書 domain_pn.csv
 
極性辞書は一般語の辞書なので、このテーマの核心語が収録されていない。
 
```
語,スコア,備考
セシウム,-0.9,放射性物質の検出
出荷停止,-0.9,規制措置
風評被害,-0.95,
全袋検査,0.1,検査体制の整備
```
 
### 使い方の手順
1. まず補助辞書なしで実行する
2. 出力の「寄与語」列を目視で確認する
3. 明らかに誤判定している見出しの原因語を特定する
4. `domain_pn.csv` に適切なスコアで追加する
5. 再実行して改善を確認する

### 注意 
補助辞書を膨らませすぎると「自分で辞書を作った」ことになり、辞書ベース手法の客観性という利点が失われる。
 
**どの語を追加したかは全て記録し、発表資料に明記すること。**
 
## 既知の限界
 
### 1. 見出しが短く、判定不能が多く出る
見出しは20〜30字程度で、極性語が0〜1語しかないことが多い。
「出回らぬコメ、悲嘆の福島　消費者も外食業者も敬遠」のように、
明らかにネガティブでも辞書にヒットせず判定不能になる例がある。
 
判定不能の割合が半数を超えるようなら、手法として厳しいという
結論自体が知見になる。
 
### 2. 1語がスコア全体を決めてしまう
 
ヒット語が1語だけの場合、その語の極性がそのまま見出しの判定になる。
「福島産コメ・牛肉、価格戻らず」が、たまたま拾った「産」の影響で
ポジティブ判定される、といった誤りが起きる。
 
**必ず「寄与語」列を目視で確認すること。**
 
### 3. 皮肉・反語を判定できない
「風評被害とか言われるの意味わからん」のような文は正しく扱えない。
辞書ベース手法の原理的な限界。
 
### 4. 地方版の重複
同一記事が複数の地方版に掲載されると別レコードになる。
件数分析では重複除去のルールを決めておく必要がある。
 
### 5. 掲載面によるバイアス
同じ「福島のコメ」でも、全国面は規制・汚染・停止の話が中心、
地方面は検査体制・試験栽培・地域の営みが中心という明確な非対称がある。
 
## 推奨する使い方
辞書ベース単独ではなく、**LLMベースの判定と併用**して一致率と不一致の傾向を分析すると、発表としての説得力が増すのかな？
 
「辞書ベースとLLMベースで判定が一致した割合は◯%、不一致だったのはこういう文」
