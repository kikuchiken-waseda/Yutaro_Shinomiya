# 先行研究調査
## LINEの特徴
### 概要
1. 実際の会話に近い感覚でテンポよくコミュニケーションが進む
2. 発言が吹き出しとして表示・共有されるので、複数人のコミュニケーションに利用されやすい。
3. 画面上にやり取りが残るため、会話が途切れてもスムーズに再開できる。
4. 異なる話題が同時並行で継続可能である。
5. スタンプで多彩な感情表現が可能である。
6. １つのスタンプが異なる文脈で使われ、多くのスタンプには意味の説明がないため、文脈から意味を汲み取り解釈する必要がある。
7. 相手の「既読」「未読」が確認できる。

```
三宅和子（2018）「SNS における方言使用の実態－エセ方言はいつ、だれ
```

### 「分かち書き」の重要性
まとまった文章をいくつかに区切ってメッセージを送信すること。
全文を打ってから送信するより、目に届く時間を早くしたり、
相手に見やすいようにレイアウトしたり、
受信する側は会話をしているかのように相槌を打てたりする。・

**引用元**
```
西川勇佑・中村雅子（2015）「LINE コミュニケーションの特性の分析」
『東京都市大学横浜キャンパス情報メディアジャーナル 4』
```

### 句点マーカー
- 句点の不可視化
  - 大学生が交換するLINEのメッセージに置いて句点の出現率は5%ほど
  - 句点を打つべきところに、書き言葉では句点が存在しない
  - LINEでは分かち書きが行われるため、送信のたびに句点を打つ必要がない
- 句点の代わりに補助的記号や特殊文字が使用される。
  - 句点の代わりに補助的記号や特殊文字が使われる
  - 打ち言葉では補助的記号や特殊文字が中心的位置にある
- 句点マーカーの使い方は個人によってさまざまな傾向がある。
